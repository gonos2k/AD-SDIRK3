## 변경·검증 범위

새 빌드용 `WRF_NATIVE_EXIT_TRACE`는 namelist/solver 옵션이 아닌 명시적 진단 전처리 정의다. 기본 빌드에서는 세 `.F` 파일의 추가 호출이 제거되고, C 관찰기도 기본 링크에 들어가지 않는다. 예전 관찰기의 constructor/destructor MPI 상태 조회는 미래 버전에서 로컬 기록으로 대체했다. F77 PMPI 초기화·종료는 원래 `ierr` 포인터로 각각 한 번만 전달한다. 실제 단계식·수송·경계·허용오차를 바꾸지 않았다.

테스트는 정상 자식·비영 자식·좀비·신호 전달, 가짜 PMPI, 실제 소스에서 추출한 종료 루틴을 사용했다. WRF 격자 상태를 적분하거나 MPI/PMIx를 실행하지 않았다. 설치된 헤더의 C 객체 컴파일만으로 실제 Fortran/MPI 전체 링크 호환성이나 native 실행 중립성을 인증하지 않는다. 선택적 새 진단 실행파일은 반드시 별도 소스·객체·실행파일 해시와 새 실행 근거를 사용하며, 완료된 쌍둥이 실험의 실행파일 바인딩을 대체하지 않는다.

## 다음 조치

현재 코드 준비 범위는 종료한다. 같은 smoke 시험이나 E0–E2를 재실행하지 않는다. 실제 필요한 다음 native 실행에 진단이 필요하다면 사용 문서에 따라 영향받는 Fortran 객체와 관찰기를 해당 스택으로 다시 빌드하고, 같은 실행에서 마지막 반환 표식과 처음 누락된 반환 표식을 확인한다. 기록의 부재 자체는 관찰기 출력 실패와 구분해야 하며 원인을 단정하지 않는다.
