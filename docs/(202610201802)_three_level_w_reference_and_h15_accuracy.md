## 수렴·재생 및 보존 범위

3,072개 Newton 수렴 행은 2/3/4단계 각 1,024개로 순서가 맞고, 모두 `iters=2`였다. 이는 초기 검사 후 보정 한 번과 최종 검사이며 Newton 보정 두 번이라는 뜻이 아니다. 출력된 정규화 잔차의 최대는 `1.1e-15`다. 이 값은 로그의 제한된 출력 정밀도로 읽은 정규화 잔차이며, FP64 전체 잔차나 W의 물리 단위 단계 잔차·전역 오차 상한이 아니다. 상태 전달은 최초 host 입력 한 번, 내부 carry 1,023번, publication 1,024번을 확인했다.

Root는 원래 NetCDF에서 새 기준 24행과 조건부 후보 24행을 별도로 계산했다. Green/Red 독립 분석과 대조한 48개 공식 행의 RMS·한도 대비 비율·판정은 Root와 정확히 일치했다. 24개 세 수준 감소비도 같고 cosine 차이는 `1e-14` 미만이다. 새 해의 초기 여덟 필드는 보존된 중간 해와 일치하며, retry/fallback/nonfinite/soft-continue/state-handoff 관련 기록된 카운터도 0이다. 새 모델은 한 번만 실행했으며 별도 수반·FD·전체 관측창 재생 시험은 하지 않았다. 기존 standalone CI의 재생은 이번 native 240초 수반의 인증과 구분한다.

## 재계산과 코드 범위

[작은 공개 재계산 묶음](evidence/three_level_w_reference/README.md)은 새 미세 해와 보존 후보의 공식 시각 필드 및 기존 차이장의 소규모 공간 자료를 제공한다. 기존 약 24.9 MB PR310 배열은 중복 복사하지 않고 상대 경로와 해시로 참조한다. 생산 코드·공개 ABI·tableau·기본 설정은 변경하지 않았다. Graphify의 검증된 생산 소스 그래프를 재사용하고 이번 오프라인 helper 여섯 파일의 작은 AST corpus(55 nodes/187 edges)만 갱신했다. 그래프는 탐색 보조이며 수치 정확성의 증명이 아니다.

분석 도구의 실행 receipt 형식도 실제 자료와 맞춰 확인했다. Green은 출력 시각 목록의 `times` 이름을, Red는 solver summary의 `steps`가 모델 스텝이 아닌 암시적 단계 수임을 반영했다. 원래 분석 소스·실패 기록과 수정 바인딩을 외부 근거에 보존했고, 이 수정은 오프라인 파싱에 한정된다. 모델 재실행·수치식·예산·판정 영역은 변경하지 않았다.

새 폴더에 재계산기·manifest와 네 데이터 입력(protocol·새 미세/후보 NPZ·기존 PR310 NPZ)을 복사한 오프라인 시험이 같은 48개 판정과 24개 방향 통계를 재현했다. 기존 큰 NPZ의 임시 복사본은 시험 후 제거했다. 최종 manifest는 이 시험 뒤 추가한 감사 자료까지 해시 목록을 확장하며, 수치 입력과 재계산기는 그대로다.
