## 결과와 선택

보존된 `h=0.9375 s`, Newton 절대 `1e-9` 계산을 새 `h=0.234375 s` 기준해와 원배열에서 직접 차감했다. 기존 네 시각·여섯 변수·물리 소유 영역과 **원래 후보용 전체 epsilon**에서 **24/24 충족**이다. 가장 제한적인 W 180초의 직접 거리/예산은 **0.5025718511**, 삼각부등식 상한/예산은 **0.5029398054**다.

이 설정을 해당 건조 `em_b_wave`·원래 e71 초기장·240초 사례의 **연구용 전방 설정**으로 선택했다. 새 모델 실행·재빌드·생산 기본값 변경은 없다. [설정 기록](evidence/research_forward_setting/research_forward_map.json)은 실제 namelist, 입력/실행파일/archive 해시, 수송·필터·경계·정밀도·상태 전달·풀이 기준과 판정 근거를 한 계산맵에 연결한다.

기존 `.9375/.46875 s` 쌍의 기준해용 `epsilon/3` 결과 **22/24**, 새 `.46875/.234375 s` 쌍의 **24/24**, 15초 후보의 전체 epsilon 결과 **20/24**는 모두 보존한다. 기준해용 한도를 후보에게 적용하거나 기준해 검사를 다시 여는 작업은 하지 않았다. 새 전방 설정은 이산 기준해에 대한 출력 기반 연구 판정이며 연속 참오차 상한·전체 3차 수렴·일반 관측창 수반 인증은 아니다.

## 고정한 전방 시간맵

명칭은 `dry_em_b_wave_e71_240s_h15over16_strict_v1`이다. 0–240초 고정 `h=15/16 s`, 256 모델 스텝·768 암시적 단계, IMEX ARK324L2SA scheme 6/mode 3다. 초기 상태는 해시 `e71b730a12e5a16d181f404f6314e7904e0165eefa622ffd0c508bf8c00dd2a9`의 원래 입력이며, source-60 입력이나 상태 전용 restart를 사용하지 않는다. 기존 성공한 연속 계산을 그대로 등록했다.

Newton 절대 `1e-9`·상대 0, Krylov `1e-7`, 유효 EWT `1e-6`, MPI 1 rank·OMP 1 thread, 내부 FP64와 연속 carry를 유지한다. 실제 경로의 native PH 옵션 1, THM 연직 차수 3, CF 세 값, mass-coordinate/omega 규칙, 비정역학, 발산 감쇠 `kdamp=0.2`, option-2 확산 `KHDIF=1000/KVDIF=10`과 경계를 유지한다. stock 음향 자식 경로는 비활성이며 namelist의 stock 필터 숫자를 새로 해석해 적용하지 않는다.

[namelist.input](evidence/research_forward_setting/namelist.input)은 실제 archived coarse namelist와 bytes가 같다(SHA `a6ea8f8ab62a74d72840ea46de4ac39a20d5d4247db77ebced0b84a1433dbdc5`). 원래 환경 override를 지운 뒤 사용한 관찰 설정과 수치 설정을 구분해 기록했다. 재현 시 임의 환경 override나 수치 이력 초기화로 다른 맵을 만들면 안 된다.

실행파일 SHA `5bf90cd95e6d5ac4a5a76f73ec407d9ee6e91c1b6919488df20c9df09a2a7769`, C++ archive `dd87b49aa448a88e13ba2047fd75b433d785f112ab485483ae439ba5035f32c5`, Fortran archive `11e6b42861a85d1ecfd4774c4272da71cb46e41a38c57c24d28b525cee09ad15`를 재사용했다. 28개 pin 기록(27개 고유 소스 bytes)과 기존 Apple clang 21·libtorch 2.10·Open MPI 5.0.9·netCDF 스택은 PR310 receipt로 연결한다. 기존 빌드의 dirty HEAD 이름만으로 생산자를 동일하다고 주장하지 않는다.

이 선택은 생산 기본 Newton 기준을 변경하거나 모든 사례에 0.9375초를 강제하는 기능이 아니다. 15초 후보는 현재 설정(Newton `1e-7` 포함)의 W 예산 미충족으로 남겨두며, 더 큰 간격의 정확도·효율은 별도 목표다.

## 다음 연결의 정확한 경계

선택한 것은 전방 설정이다. 같은 맵의 접선·수반·관측창 검증이 완료됐다는 뜻은 아니다. solver-entry 상태 이후의 맵과 파일 초기화맵의 미분도 구분한다.

기존 fixed-trajectory API는 accepted endpoint의 cotangent를 역순으로 합성할 수 있고, native PH/THM/CF 옵션·보조 상태·carry fingerprint를 유지해야 한다. 반면 Fortran 고정 궤적 wrapper가 존재한다는 사실만으로 실제 WRF 관측 목적함수가 그 수반을 호출한다고 볼 수 없다. 기존 작은 U/V standalone/통합 경로 차이, THM Taylor 미결과 실제 관측창 연결은 자동으로 닫지 않았다.

다음 검사는 이 시간맵의 실제 입력·옵션·경계·상태 전달을 유지한 경로에서 기존 JVP/VJP·재생 도구를 연결하는 범위다. 관측 H·물리 sampling·시각·R·control/prior·미분 예산은 실행 전에 명시해야 한다. 이번 예측 평가시각 60/120/180/240초는 accepted 스텝 64/128/192/256에 대응하지만, 이를 자동으로 새 관측 스케줄로 채택하지 않는다. **예측 오차 예산 epsilon은 관측 공분산 R이 아니다.** 새 관측 문제·AD 엔진·물리조건·최적화 사례는 추가하지 않았다.
