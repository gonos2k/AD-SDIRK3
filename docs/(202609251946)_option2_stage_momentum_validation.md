# Option-2 stage-local momentum geometry and bounded validation

Timestamp: 2026-09-25 19:46:04 JST (+0900)

## Context and source contract

This candidate is stacked on draft PR #234 (`204932cdf10bab53ef79c49c55d51dd4aac6a110`); the validated code/test HEAD before this documentation consolidation is `0762f9e2f23780328ae68237ebcc891f6c00e0af`. WRF's `compute_diff_metrics` makes W-level backward-face `zx/zy` and vertical `rdzw/rdz` from `(PH+PHB)/g`. The option-2 scalar RHS already used current-stage geometry, while U/V/W deformation read base-state centered-slope and vertical-metric caches and later used current PH for parts of stress divergence. The mixed definitions did not represent a single geometry at a fixed RHS state.

The C++ implementation now forms one immutable, differentiable stage metric snapshot from the current `ph_full_for_diff` and explicitly passes it to option-2 U/V/W deformation and stress-divergence helpers. The caches remain for option-1 and legacy callers; no RHS evaluation writes them. Explicit-stage mass-grid `rdz` is averaged to U/V shear faces. Packed periodic X interpolation uses N unique mass columns, forms N+1 true U faces, then copies face 1 into the extra packed alias. The supported dispatch is limited to a dry, canonical periodic-X/symmetric-Y, `km_opt=1`, `damp_opt=0`, complete one-rank tile with WRF eta weights and no supplied diffusivity or face capture. Unsupported native option-2 requests fail closed.
