## 하나의 사전 고정 판단

같은100km·h600·mode3·FP64 carry·reuse OFF·원래 최종/선형 허용오차를 유지한다.
독립 초기장의 한 스텝씩 A0–B0–B1–A1을 최대4회, 재시도 없이 수행한다. 각 case는 시작/끝
history만 출력한다. 첫 유효 A0의 실제 선형화 문맥에서 후보 expected header를 고정한다.
새 후보는 첫 stage2/Newton0 FGMRES에만 P0를 적용하고, 다른 다섯 선형계는 원래 경로다.
별도 결합 최적화·시간간격·감쇠·EW 변경·장기 적분은 수행하지 않는다.

기존 뉴턴점 입구부터 첫 FGMRES까지의 비용에는 공통 RHS/전처리 준비, 문맥 확인, 후보
준비와 실제 잔차 확인을 포함한다. scaled A 호출/시간과 scaled M 전체 호출/시간을 나누고,
physical M 시간은 scaled M의 포함 항으로만 보고 합산하지 않는다. 나머지는 직교화·소형대수·
관찰 복사 등을 포함하며 특정 함수의 독립 비용이라고 부르지 않는다.

첫 Arnoldi의 기존 v와 A(Mv)를 직교화 전에 한 번 복사한다. 새 RHS/JVP는 호출하지 않는다.
복사 시간은 측정 구간에 포함하고 별도 기록하며1% 초과이면 비용 표본을 거부한다.
노름·물리 S 변환·파일 출력은 구간 종료 뒤에 수행한다. 초기 v는 모든 case에서 바이트
일치를 요구한다. block-scale0/IdentityS만 지원해 weighted V와 raw w를 섞지 않는다.
출력 block 노름은 packed이며 소유점·고Y파수 진단은 별도 물리 마스크 후처리다.

기존 초기21배열/8속성, 수렴·참잔차·fallback·여섯 소유장 화면·rank/환경·자원 조건을 유지한다.
벽/단조시계 차이1초, snapshot1%, 사후 rank RSS4GiB, 전후 disk5GiB 조건을 실행 전에
고정한다. 하나라도 실패하면 해당 블록은 NO-GO이고 추가 표본·합격선 조정은 하지 않는다.
모든 조건을 만족한 경우에도 두 mirror pair 각각과 그 중앙값이 준비 포함2배 이상일 때만
다음 제한 단계를 검토한다. 이는 계측된 첫 점의 선별이며 전체 예보·RK3 대비 속도 주장이 아니다.

이 문서 작성 시 새 native 실행·비용 비교는 하지 않았다. 보존된 RK3 기준은 초기/끝값과
그림 대조에 재사용한다. 첫 Arnoldi 차이는 물리 Newton rate 좌표의 선형계 방향이고
실제 W 예측장이나24–36시간 잡음의 인과 증명이 아니다.
