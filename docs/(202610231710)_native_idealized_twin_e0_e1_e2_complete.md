## 고정한 문제와 구현

제어점은 WRF 초기화와 CQ 처리 이후 solver 진입 상태다. 원래 수치 참궤적을
해시로 고정하고 실제 E0 전방으로 재사용을 검증했다. E0는 참상태 중심 b=0,
E1은 오차가 있는 배경장 중심 a=0이다. 바람 모드는 실제 ZNU와 C-grid curl에서
U/V를 공통 최대 0.1 m/s로 정규화했고, 온위 모드는 최대 0.01 K다.
전체 packed P에 주기·대칭 경계 확장을 포함하여 P·lambda0로 제어 기울기를 계산했다.
물리 압력은 기존 EOS가 진단하며 압력이나 W를 참값으로 강제하지 않았다.

관측은 120·240초의 U/V/건조 총 온위(T+300), 변수별 64점, 총 384개다.
1부터 시작하는 소유 순번 {2,6,10,14}를 실제 native stagger의 전역 인덱스,
좌표와 packed 슬롯으로 기록했다. 같은 목록으로 select와 scatter-add를 수행했다.
고정 sigma는 U/V=0.05 m/s, theta=0.01 K이며 비용은 관측 수로 평균하지 않는
0.5*sum(r^2/sigma^2)다. 잡음과 배경 벌점은 없고, sigma는 실제 관측오차 추정값이 아니다.

생산 방정식, tableau, 수송·확산·CF·감쇠·경계, 공개 ABI와 기본 허용오차는
변경하지 않았다. Newton 절대 1e-9/상대 0, Krylov 1e-7, EWT 1e-6,
MPI 1 rank/OMP 1, 내부 FP64 carry와 실제 Fortran FP32 cotangent 연결을 유지했다.
메모리 내 마지막 32스텝만 기록하고 원래 초기상태부터 prefix를 재생했다.
상태만 읽는 cold restart는 사용하지 않았다. 비용 전방 모드는 VJP를 호출하지 않는다.

새 코드는 테스트 전용 FP64 초기 제어 seed와 forward-only 경로,
제어·관측 생성기, 기존 checked pullback caller와 bounded 최소화 연결이다.
같은 8개 FD 전방을 두 폭(0.01/0.03)의 384×2 민감도와 비용 기울기 검사에 재사용했다.
최초 SVD 특이값은 약 8.2888533/3.7214081, 두 폭 행렬의 차이 노름은 2.9135e-8이다.
중간 항은 전체 신호와 별도로 검사했고, 중간 누락·시각·중복 주입·sigma^2 대신 sigma 사용
오류과 관측의 비유한값·가중·ID·격자·슬롯 오류를 검출했다.

## 실제 계산과 수치적 연결

전체 native 시도는 41회·6,880 모델 스텝이다. 39회는 종료 코드 0과 기존 게이트를
통과했으며 두 MPI 런처 종료 코드 1 기록은 **실패로 보존**했다. 실패한 시도도
165회·28,992스텝의 원래 총 예산에 포함했다. E1의 12 수용 갱신·40 비용 전방·
13 기울기 평가 한도는 늘리지 않았다. 상세 prefix 재생 비용은 전방 비용과 별도 집계한다.

첫 MPI 실패의 동일 seed/reference/cotangent 대조는 정상 종료했고 배열이 바이트 일치했다.
두 번째 실패는 잠자기 시간 차이가 없었으므로 잠자기를 원인으로 단정하지 않았다.
F77 MPI_Finalize를 PMPI에 정확히 한 번 전달하고 상태만 기록하는 별도 계측 실행파일로
해당 192스텝만 진단했다. MPI 반환 ierr=0, finalized=1, 프로세스 종료 코드 0을 확인했으며
193개 FP64 체크포인트와 FP64/FP32 기울기가 실패 실행의 배열과 바이트 단위로 같았다.
이 저장된 **한 구간 자료만** 정확한 호출 인자·공통 객체·링크 차이·배열 해시 증거로
연결했고, 이후 다섯 계산은 원 실행파일로 정상 완료했다. 이전 MPI 오류의 원인은
미확정이다. 계측 실행파일의 일반 동등성이나 MPI 배포 신뢰성을 주장하지 않는다.

E0의 초기 V 북쪽 ghost 272개에는 -0/+0 표현 차이만 있었다. 초기 수치 값의 일치와
부호 0 차이를 기록하고, 수용된 1–256스텝은 참궤적과 바이트 일치함을 확인했다.
실제 수반 호출을 생략하거나 저장된 참값을 그대로 반환하는 E0 우회는 사용하지 않았다.
실행 준비의 경로 반환 오류도 수정했으며 실패 기록과 원래 실행은 보존했다.
