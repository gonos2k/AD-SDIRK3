# 등록 native 시간맵의 종단 수반 연결

작성: 2026-10-21T02:22:51+09:00 (JST, UTC+09:00)

PR #311에서 확정한 `dry_em_b_wave_e71_240s_h15over16_strict_v1`의 실제 WRF 경로에 종단 목적함수와 기존 checked Fortran pullback을 연결했다. 선택한 목적함수 하나와 혼합 방향 하나에서 전방–상태 재생–수반–독립 방향차분 검사를 통과했다. 원래 작업트리는 수정하지 않고 별도 작업트리에서 수행했다.

## 실제 연결과 수정

Fortran의 RK1 호출이 전체 ARK 스텝을 계산한 뒤 RK2·RK3 호환 호출이 들어온다. 기존 `advanceZeroCopy`는 호환 호출에서도 문맥을 먼저 갱신했다. Fortran `DAMPCOEF`에서 온 약 0.01이 실제 단계의 `SDIRK3_KDAMP=0.2`를 덮어써, 기록된 궤적의 fingerprint 검사에서 pullback이 거부됐다.

`advanceZeroCopy`는 여섯 격자 차원을 먼저 검증하고, 활성 고정 궤적이나 단계 그래프가 있는 호환 호출을 문맥 갱신 전에 반환하도록 수정했다. 그래프 생성 전의 기존 설정용 호출은 유지했다. fingerprint 검사는 그대로 적용한다. 실제 RK1 수치식·tableau·공개 ABI·생산 기본 허용오차는 변경하지 않았다.

기존 `Fixed_Trajectory_Lifecycle` 시험에 RK2·RK3의 상태·계수·스케줄 보존, 잘못된 격자의 거부, 이후 스텝과 pullback 완료를 추가했다. 새 native 시험 연결은 `WRF_SDIRK3_NATIVE_TERMINAL_TEST`를 정의한 검증 빌드에서만 활성이다.

## 고정한 계산 문제

건조 `em_b_wave`, 물리 격자 16³, 수평 100 km, 상단 설정 16 km, MPI 1·OMP 1이다. h=0.9375 s로 256스텝·240초를 계산한다. Newton 절대 기준 1e-9·상대 기준 0, Krylov 1e-7, EWT 1e-6, 내부 FP64 연속 전달을 유지했다. PH 옵션 1, scalar 연직 차수 3, 실제 CF, native 발산 감쇠 0.2와 option-2 확산도 유지했다. 등록된 전방 정확도 24/24와 기준해 민감도 24/24는 다시 열지 않았다.

제어점은 초기화와 CQ 처리가 끝난 첫 native solver 진입 상태다. packed 차원은 24,531이며 순서는 U·V·W·PH·T·MU, 저장 순서는 [j,k,i]다. 입력 파일부터의 초기화 미분은 이번 범위에 포함하지 않았다.

종단 목적함수는 물리 W 소유점 4,096개의 고정 정규화 사인 가중을 0.001 m/s로 나눈 선형 함수다. 하단 고정면은 제외하고 동적 상단을 포함한다. 실제 한 번 반올림한 FP32 cotangent를 FP64로 승격하여 내부 종단 상태와 내적했다. 초기 방향은 여섯 블록의 물리 척도를 반영한 고정 혼합 방향이며 주기·대칭 경계와 W/PH 고정 하단을 보존한다.

모든 섭동은 실제 전달된 FP32 eta를 FP64로 승격해 내부 초기상태에 적용했다. 여섯 실제 초기 seed의 총 온위·기둥질량·지오포텐셜 층두께는 모두 양수였다. 최소값은 각각 302.2343 K, 89091.7819 Pa, 9247.3528 m²/s²이다. 이는 초기 seed의 허용성 검사다.

## 메모리와 시간맵 재생

기존 API로 32스텝 구간 8개의 pullback을 합성했다. 각 구간은 원래 초기장에서 실제 Fortran 시간진행을 재실행하고 마지막 32스텝 그래프만 유지한다. 각 구간에서 실제 Fortran FP32 반환값을 다음 역방향 구간에 그대로 전달했다. 구간별 내부 FP64 기록은 이 FP32 입력의 국소 pullback을 변환하기 전의 값이다.

| 검증 | 직접 확인한 결과 |
|---|---|
| 최종 선택 계열의 실제 실행 | 13개 프로세스, 2,432 모델 스텝, 7,296 암시적 단계 정상 종료 |
| 새 상태 전방 재생 | 257개 FP64 packed 상태 바이트 일치 |
| 일곱 prefix의 전방 재현 | 총 903개 끝값이 기준 prefix와 바이트 일치 |
| 실제 Fortran 가중값 연결 | 8개 구간 입력·이전 반환값 일치, 반환값과 국소 FP64→FP32 변환 일치 |
| 수정의 전방 중립성 | 수정 전 보존 V4 전방과 V5의 257개 packed 상태 일치 |
| 기존 연구 전방과의 연결 | 17시각×8개 공개 필드 136개 배열과 내부 W 257개 배열 일치 |
| 최종 계열 최대 RSS | 4,069,195,776 B, 사전 18 GiB 한도 이내 |

단일 256스텝 그래프 보존의 자원 중단과 반복 구간 보존의 RSS 증가 시도는 원자료에 실패로 보존했다. RSS 증가의 일반적인 누수 원인을 확정하지 않았다. 이후 사용한 프로세스별 단일 구간 방식은 위의 실제 재현 검사를 거쳤다. V4의 첫 pullback fingerprint 거부도 보존했다.

후처리 판독 오류는 생산 계산과 구분했다. 구간 요약과 끝값 기록의 항목 위치, eta=0의 signed zero, warm=0일 때 별도 suffix seed 파일이 없는 형식을 바로잡았다. 마지막 경우는 실제 초기 seed와 checkpoint 0, 기준의 첫 상태를 대조했고 원자료 파일을 만들어 보충하지 않았다. 이 수정에 따른 모델 재실행은 없었다.

## 독립 방향차분 결과

실제 연결한 초기 FP32 기울기를 승격하여 얻은 값은

\[
d_{AD}=v^T\lambda_0=-11052.647841641348
\]

이다. 각 FD의 분모에는 명목 소수값 대신 실제 FP32 eta를 사용했다. 오차 분모는 사전 규칙인 max(|dFD|,|dAD|)이며 별도 바닥값을 넣지 않았다.

| 명목 폭 | 실제 양의 eta | 중앙차분 | 수반 대비 상대차 | 단측 기울기 상대 차이 |
|---|---:|---:|---:|---:|
| 0.01 | 0.009999999776482582 | -11052.647887059557 | 4.11e-9 | 4.83e-5 |
| 0.03 | 0.029999999329447746 | -11052.64768227135 | 1.44e-8 | 1.45e-4 |

두 중앙차분의 상대 차이는 1.85e-8이며, 두 폭 모두 사전 1% 비교 기준을 충족한다. 목적함수의 양·음 차이는 221.05와 663.16으로, 반올림 신호 판단선 5.92e-6보다 충분히 크다. 구간별 FP64→FP32 변환의 상대 L2 차이는 약 2.07e-8–2.91e-8이며 전체 기울기의 정밀도 오차 상한으로 해석하지 않는다.

상류 부호의 변화도 기록했다. 재생은 같은 기록 순서에서 부호 차이가 없고, 섭동 실행에는 차이가 있다. 같은 host step·호출 ordinal·형상을 맞춘 진단이며, 서로 다른 섭동의 물리 평가점이 완전히 같다는 뜻은 아니다. 유한한 두 폭의 단측 검사는 일반적인 고전 미분가능성의 증명이 아니다.

## 원자료와 재계산

[작은 검증 자료 묶음](evidence/native_terminal_adjoint/README.md)에 실제 seed·종단 상태·방향·가중값·8개 구간 기울기를 담은 4,232,280 B NPZ, 원형 그대로 복사한 13개 실행 receipt, 빌드·소스·실행파일 지문, 상태 재생 증명표, Green·Red 검토를 보존했다. 전체 checkpoint·NetCDF·로그는 manifest의 외부 증거 경로에 그대로 보존했다.

```sh
python3 docs/evidence/native_terminal_adjoint/recompute.py \
  --npz docs/evidence/native_terminal_adjoint/native_terminal_adjoint.npz \
  --manifest docs/evidence/native_terminal_adjoint/manifest.json \
  --output /tmp/native_terminal_recomputed.json
```

NPZ SHA-256은 `c642672fb329fa60be5b29bd105d0476bbbc16cb00eb872fb15b874d0d816c36`이다. 휴대용 재계산은 NumPy만 요구하며 모델이나 생성 실행파일을 실행하지 않는다. 전체 원시 checkpoint를 새로 비교하는 기능은 없고, 포함된 receipt의 ledger 해시를 대조한다. 실제 바이트 비교는 원자료 검산과 별도 증명표에 기록했다. 정상 종료와 수치 조건 충족은 출력 JSON의 판정 필드로 구분한다.

V5 생산자 소스는 `559b7a861105e5db5838f1a933a6661111aec1cb`, P6는 `a9c256e487574e01c3bf0231a94fec0630c69d7f`다. 두 실행파일 SHA-256은 각각 `1a05828d1c5c941ed43cd9011bc52973ed950f469f537d1c6e48cd64d3b45853`, `71927be0736ecd7c8e51b4a22177122af1a38b924e345836d1d6590470514249`다. P6는 같은 수치 핵심 객체를 재사용하고 시험 연결부만 갱신했다. 클래스 헤더와 소비 객체의 일치·아카이브 구성·심볼·링크를 확인했다. 전체 기록은 `build_provenance.json`에 있다.

네이티브 빌드는 Apple Clang 21, GNU Fortran 15.2, Homebrew Open MPI 5.0.9, netCDF 4.9.3/Fortran 4.6.2, libtorch 2.10.0(C++17, ABI=0)을 사용했다. 기본 PATH의 다른 netCDF 도구와 구분해 실제 Homebrew 링크 경로와 명시적 도구 버전을 확인했다.

Graphify의 검증된 수치 소스 관계를 재사용하고 영향받는 호출 경로를 소스와 대조했다. 새 NumPy 검산기의 AST와 소스 지문을 갱신했다. Fortran 연결의 제한된 추출은 직접 소스 검토로 보완했으며, 그래프를 수치 증명으로 취급하지 않았다.

## 회귀와 기존 RK3 자료

소스 a9의 GitHub CI [39448674758](https://github.com/gonos2k/AD-SDIRK3/actions/runs/39448674758)는 기존 CTest 5개를 통과했다. RK2·RK3 문맥 보존 표식도 확인했다. raw ZIP SHA·CRC를 확인하고 retained/replay 초기 pullback 8,480성분의 FP64 바이트를 직접 대조했다. CI의 16개 끝값 일치 표식은 실행 메타데이터이며, 위의 native 257개 상태 직접 비교와 구분한다.

같은 e71 입력·16³ 격자의 보존된 stock RK3(h=1.875 s)와 선택한 h=0.9375 s 전방의 240초 거리도 [기존 자료](evidence/native_terminal_adjoint/archived_rk3_context.json)를 재사용한다.

| 변수 | 보존 RK3와의 RMS 거리 |
|---|---:|
| U | 1.35072337e-2 m/s |
| V | 3.57187657e-3 m/s |
| W | 3.19813592e-4 m/s |
| PH | 2.57214219e-1 m²/s² |
| T | 1.11422877e-4 K |
| MU | 5.04088943e-1 Pa |

두 방법의 stock 음향 필터와 native 감쇠 정책이 다르므로 이 표는 보조 거리이며 정확도 기준이 아니다. 기존 coarse의 단계 관찰 포함 wall time은 872.94 s, RK3의 과거 analysis에는 1.93578 s가 있으나 대응 wall receipt가 없다. 이번 baseline의 1683.94 s에는 전방과 두 국소 pullback이 포함된다. 이 값들로 속도비를 산출하지 않았다. 이번에 새 stock RK3 적분이나 동등 구간의 실행시간 비교는 수행하지 않았다.

## 완료 범위와 다음 작업

등록한 건조 사례의 고정 종단 목적함수·혼합 방향에 대한 실제 native 전방–상태 재생–구간 수반–방향차분 연결을 완료했다. Green 원자료 집계와 Red 독립 원배열/휴대용 재계산 검토에서 범위 내 중대 미해결 결함은 없었다.

일반 관측창의 다중시각 가중값 주입, 전체 시간맵 JVP, 모든 방향의 미분가능성, 초기화맵 미분, 독립적인 전역 FP64 수반과 두 번째 전체 native 기울기 재생은 이번에 인증하지 않았다. 기존 별도 C++–native 경로의 작은 U/V 차이와 THM Taylor 미결도 개별 범위로 유지한다. 기존 h=15 s 후보의 20/24 판정과 W 네 시각 미충족도 유지한다. 다음은 필요한 관측시각의 목적함수 기여를 같은 시간맵에 주입하는 연결이다.
