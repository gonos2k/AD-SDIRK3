## 하나의 결합 연산자

`P1=P0−a C`, `C=E_V(Jprimary−Jref,V)`, `Jref,V=(x−P0x)_V/a`로 정의했다.
`z0=P0^-1r`, `g=Cz0`에 대해 `(I−a C P0^-1)y=g`를 풀고,
저장한 `Xi=P0^-1 vi`로 `z=z0+a Σ yi Xi`를 복원했다. V뿐 아니라 μ·온위·PH·W의
P0 결합 응답을 유지한다. 최대4 Arnoldi, restart0, 실제 축약 상대잔차0.01로 고정했다.
이것은 내부 근사 전처리 조건이며 원래 A나 최종 허용오차를 바꾼 것이 아니다.

FGMRES는 각 실제 Z를 저장하므로 방향별 내부 종료횟수 변화도 올바르게 처리한다.
대칭·SPD·nilpotence나 보편적 수렴은 가정하지 않았다.

비대칭 작은 직접해와 실제 ReferencePressureModel/PressurePackedAdapter 검사에서
소거·모든 행 복원, 비영 Phi0·벽·주기 alias, budget/NaN/특이/할당 예외를 검사했다.
