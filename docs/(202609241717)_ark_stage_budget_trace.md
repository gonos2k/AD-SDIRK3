# Accepted ARK-stage budget trace for a closed hybrid tile

Timestamp: 2026-09-24 17:17:45 JST (+0900)

## Context and change

This work starts from PR #216 commit `c90ff20b21043c9e7fd5bcdd96e81b449e63563b`, which itself is stacked on open PR #215. It addresses checklist S1a only. A default-off test observer copies the **accepted** ARK324 stage state and fast/slow/full tendencies, the raw final tableau update, and the final projected state. It does not re-evaluate the RHS or change the accepted step. The existing `Full_Tile_Step_Adjoint` hybrid case uses nonuniform eta, variable WRF hybrid coefficients, a smooth nonunit map, positive layer mass, fixed horizontal diffusivity, periodic X and symmetric Y boundaries, and zero caller-supplied physics tendency.

At every stage, the test integrates `A/g * MUdot` and `A*|dnw|/g * [L*thetadot + c1h*theta*MUdot]`, where `A=dx*dy/(msftx*msfty)` and `L=c1h*(MUB+MU)+c2h`. It compares accepted fast MU to `msfty * diagnose_wrf_mass_flux(...).mass_tendency_over_map_y` on the same stage state. The mass-flux helper's periodic seam, impermeable Y wall and top/bottom Omega are checked. The raw ARK update is replayed in tableau order from the accepted derivatives and compared exactly; the final projection/writeback and mass/theta projection deltas are checked separately.

This is a **closed-domain stage net-rate contract**, not a full physical flux/source budget. The theta face fluxes and internal sources are not individually recorded. The difference between endpoint mass-weighted theta and weighted stage chain-rule rates is reported as `theta_endpoint_minus_stage`; it includes the nonlinear product's ARK defect and FP32 effects and is not asserted to vanish. The existing `stage_operand_diag` independently aborted on this hybrid fixture at `hist_rel=1.523801e-6`; its cause is O1 in the checklist, not silently treated as an accepted stage-budget result.
