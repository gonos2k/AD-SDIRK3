# PR309 종료 수용 감사

감사 시각: 2026-10-15 23:53 JST.

## 판정

범위 내에서는 통과다. 이번 결과는 기존 V3 기준을 변경하지 않고, 같은 입력·실행파일·물리 설정에서 Newton tolerance `1e-9`를 사용한 `h=0.9375/0.46875 s` 0–60초 쌍의 사전등록된 검사다. 두 실행은 각각 64/128 스텝을 모두 수용했고, 65개 공통시각과 초기 6개 packed 상태가 일치했다. 공식 t=60 V3 비교는 저장 NetCDF FP32 값을 FP64로 올리고 고정 소유점에서 계산했다.

| 필드 | RMS(fine−coarse) | 고정 ε/3 | 비율 |
|---|---:|---:|---:|
| U | 2.33502123e-8 m/s | 2.58147235e-4 | 9.05e-5 |
| V | 5.28000000e-9 m/s | 3.37400241e-5 | 1.56e-4 |
| W | 1.79844365e-6 m/s | 2.59814662e-6 | 0.6922 |
| PH | 1.02890808e-4 m²/s² | 3.41658351e-3 | 0.03012 |
| T+300 | 0 K | 1.20652380e-5 | 0 |
| MU+MUB | 0 Pa | 4.86363349e-3 | 0 |

Green과 독립 Red가 6개 t=60 RMS와 65시각 W 진단을 일치시켰다. 576개 암시적 단계 G 요약과 192개 국소 증가량 요약도 독립 계산 간 차이가 각각 `3.16e-30 m/s`, `1.27e-29 m/s` 이하였다. 이 국소 잔차 증가량은 후속 상태 전파를 포함한 전역 오차 한계가 아니다. 실제 로그 감사에서 gate/retry/fallback/nonfinite 카운터는 64·128개 단계 모두 0이었다.

고정 εW/3을 넘은 내부 FP64 W 시각은 없었다. 최대 RMS는 56.25초에서 `1.96831049e-6 m/s`였고, 사전규칙의 마지막 구간 `[59.0625,60] s`를 상세 구간으로 선택했다. 이 진단은 t=60 공개 출력 화면과 별도다.

실행은 사전 승인된 두 건뿐이다. 빌드 출처는 PR307 빌드 영수증의 HEAD `192c914`와 나중에 커밋된 observer 소스 `18abbe9`를 구분하며, 개별 소스 bytes와 실행파일·archive 해시를 고정했다. Red 검산은 모델 실행·빌드·생산 소스 수정을 하지 않았다.

## 판정의 한계

통과한 것은 새 strict 계열의 이 60초 six-field screen뿐이다. 120·180·240초 검사와 기존 24개 변수·시각 검사(4시각×6변수) 기준해 적격성은 미확인이다. PR306의 `1e-7` 20/24 실패를 소급 변경하지 않았고, V3의 예산을 프로젝트 전역 목표로 채택하지 않았다. 참오차·수렴차수·예측 정확도·효율 우위나 수반 완료를 주장할 수 없다. 보존된 stock RK3 비교는 다른 필터 정책의 보조 거리다.
