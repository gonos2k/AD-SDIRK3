# Production RHS split-invariant probe

`probe.cpp` calls the actual production `computeUnifiedRHS` via the existing `TileCase::rhsAt` helper, on the same packed state for Full, ImplicitOnly, and ExplicitOnly. It uses the archived build's source fixture and static library; `build_run.py` extracts the fixture target's exact Ninja compile/link flags and runs without rebuilding that library or modifying production files. `t.step(1e-4)` first establishes the fixture's geometry and cached auxiliary fields; the tested state is then explicitly manufactured from zeros. The tile is 8x6x4 at 100 km, flat unit maps, f=0, uniform 80000 Pa dry base mass, c1h=1, c2h=0; U=20 m/s, V=2 sin(pi j/6) m/s at faces, vertically uniform. Theta and geopotential perturbations and mass perturbation are zero; the existing fixture checks positivity of full thermodynamics, mass and geometry. Results are restricted to j=1..4, k=1..2, i=2..6 for U. Fast mass tendency is evaluated at all mass cells. These are deliberately selected interior cells, not a complete WRF boundary assessment.

With these fixtures, constant transverse U should have zero Full physical tendency. Full U max is 2.71e-20, Fast U and Slow U max each 1.46410151598e-4 m/s², with opposite signs; full packed Full−Fast−Slow maximum is 0. Fast mass tendency max is 0.799999979790 Pa/s. Independently averaging adjacent mass tendencies to U faces and computing −U c1h mudot/(c1h*80000+c2h) reproduces Fast U within 2.71050543121e-20 m/s². In this state only, adding the opposite of this correction to Fast and subtracting it from Slow preserves Full and reduces both U maxima to 2.71050543121e-20 m/s². This algebraic readout is not a code change or a general correctness proof for resplitting; it identifies a split-invariant failure and a candidate structural direction requiring derivation and broader tests.

The implications for WRF stage convergence, other state variables, nonuniform coefficients, boundaries and distributed halos remain unverified.

## FP64 scalar and EOS derivative

The packed theta variable is **perturbation** t=θ−300 K, so the raw scalar conversion subtracts t times mass tendency, not full θ. Both experiments use an FP64 packed state and same geometry. `run.log` uses t=0 (physical 300 K); `run_theta10.log` uses t=10 (physical 310 K). Reproduce the latter with `./probe theta10` after `python3 build_run.py`. Mass and theta extrema below use interior mass cells j=1..4, k=1..2, i=1..6. PH extrema cover the full tile; all maxima are absolute.

| quantity | θ=300 K | θ=310 K |
|---|---:|---:|
| Full / Fast / Slow theta (K/s) | 0 / 0 / 0 | 0 / 7.32050758e-5 / 7.32050758e-5 |
| Full / Fast / Slow PH (m²/s³) | 0 / 0 / 0 | 0 / 0 / 0 |
| Full / Fast / Slow mu (Pa/s) | 0.585640606 / 0.585640606 / 0 | same |
| Fast p directional derivative (Pa/s) | 0.717409743 | 0.726881216 |

For t=10, the opposing theta components match −t mudot/80000 to 9.49e−20 K/s, while Full theta is zero. In both runs, the complete packed Full−Fast−Slow is zero. Thus the hypothesis that subtracting full physical theta would cancel the Fast pressure response is not supported by this implementation or fixture.

At this stage point, `calc_p_rho_wrf` uses α=(α_base M_base+|rdnw| Δφ')/M, M=80000+μ', p=p0[rd(300+t)/(p0 α)]^κ, κ=cp/cv. Therefore, at μ'=φ'=0, pdot/p=κ[t_dot/(300+t)+μdot/80000−|rdnw| Δφdot'/(α_base*80000)]. Fast PH and ΔPHdot are zero here. At θ=300 K the pressure response is entirely its mass term. At θ=310 K the maximum magnitudes of the pressure mass and theta contributions are 0.751110590 and 0.024229374 Pa/s, respectively, and have opposite sign. The printed analytic pdot was checked against a centered finite difference of the actual `calc_p_rho_wrf` evaluated at x±0.01 s times Fast RHS: max discrepancies are 7.02e−10 and 3.31e−9 Pa/s, respectively. This is a pointwise local EOS directional derivative, not a demonstration of a complete acoustic eigenmode, WRF timestep stability, or a general split repair.
