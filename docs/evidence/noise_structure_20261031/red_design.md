## Actual patch review — build blocker

The reviewed 19-line candidate assigns the repartitioned derivative to `mu_tend_for_conversion`, but the existing `mu_tend_scaled = mu_tend_for_conversion` is then packed into the output μ component. Consequently fast μ tendency is incorrectly zero and slow μ tendency incorrectly receives continuity. The new Full−Fast−Slow closure test cannot detect this because their sum remains the same. Fix by preserving the original μ tendency in the packed RHS, then assert separately fast μ equals native continuity, slow μ is zero, and the same holds for directional JVP. Check guard fallback and numerical Full equality separately. `canonical_horizontal` already implies non-export via `use_wrf_mass_flux`; guarding Full before reading experiment flags avoids unnecessary hot-path work. In the examined current implementation momentum and theta advection are all within do_explicit; comments claiming all advection implicit are stale. The zadvect option is additionally used for the W damping threshold, so its conservative guard should not be described as proof that all W transport otherwise changes ownership.
