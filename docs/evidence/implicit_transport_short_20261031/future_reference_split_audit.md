# Reference-transport split: conditional design audit

Read-only mathematical/source navigation; no implementation, new mode, JVP approximation, build, or model run. This is a future structural candidate, not evidence for the cause of late W noise or a speed improvement. Scope below assumes the same projected state, stage reference, stagger/metrics, physical boundary policy and current diagnosed WRF mass flux and Omega for both partitions.

## Coupled and physical equations

For one scalar perturbation q=t=theta−300, let L=c1(mu+mub)+c2 and Ldot=c1*mudot. Let C(U,q) denote the actual map-weighted signed divergence of the native high-order horizontal and vertical producer face fluxes, using *current* U for Ru/Rv and Omega but q as the transported scalar. Let r be a reference scalar and C(U,r) use the identical divergence and face conventions. For a fixed common reference r, set

    mudot_I = mudot(U),             mudot_E = 0
    L*qdot_I = C(U,r) − q*Ldot
    L*qdot_E = C(U,q) − C(U,r).

Add existing sources/diffusion to their original partition. Summation gives the original Full physical tendency, `L*qdot = C(U,q) − q*Ldot`, exactly in real arithmetic. Fast and Slow each have a raw conservative flux: the Fast faces F(U,r), the Slow faces F(U,q)−F(U,r). Summed physical theta (=300+q) adds `300*Ldot` in Fast; its corresponding coupled flux includes 300 times the current mass flux. Account for the production epsilon in theta denominator and actual arithmetic order when testing; do not claim bitwise equality from symbolic algebra.

For q=r=q0 spatially constant, if and only if the actual discrete metric/stagger/Omega continuity identity gives C(U,q0)=q0*Ldot, both partitioned q tendencies vanish. If q is constant q1 but r=q0≠q1, then qdot_I=(q0−q1)Ldot/L and qdot_E=−qdot_I: Full is stationary but partitions are not. For spatially variable r, even a spatially constant current q generally produces nonzero partition tendencies. Thus invariant preservation requires a reference chosen consistently on the stationary manifold and actual U/V/W wall/lid constraints; a generic frozen reference is insufficient. Stage-base r=U_stage can preserve a uniform-q manifold inductively in exact stage solves if the entire history and boundary projection preserve that manifold and no source changes q, but this is a conditional theorem, not an observed WRF result.

For momentum the same algebra is valid only after deriving each actual raw accumulator and stagger-specific Ldot/L conversion. Existing U/V conversion uses native level masses and staggered mu, while W uses W-level coefficients and the special lid operator. `wrf_horizontal_momentum` uses periodic-X/symmetric-Y and odd normal-V wall semantics. An arbitrary nonzero spatially constant normal V is incompatible with impermeable walls; constant-W must respect bottom/lid conditions. No general momentum/KE conservation or constant-field guarantee follows without an independent face/dual-continuity proof for all staggers and hybrid levels.

## Newton, reference and order

At fixed r, Newton differentiation of C(U,r) must retain derivatives through current Ru/Rv, current mu and Omega. This removes direct transported-field derivatives of C with respect to q while retaining those through mass flux, sign/limiter selection and the product-rule term `−q*Ldot`; it is not a promise of a cheap or small Jacobian. Gradients of r with respect to the initial state and prior stages remain part of a future full-step tangent/adjoint: freezing r *within the Newton variable* does not justify globally detaching r from trajectory derivatives. Any FD check must hold r fixed exactly as FWAD does.

Current code does not provide one invariant reference automatically: `solveImplicitStage` sets `U_ref_stage_=U_stage.clone()` (`tile_unified_impl.cpp:13944`); optional `omega_update_ref_per_newton` overwrites it during the solve (`:14035`); `compute_k_slow` overwrites it again with `U_conv` (`:6968–6975`). The initial explicit stage also requires an explicit reference-lifecycle audit. Simply reading the existing reference in both partition evaluations can therefore yield different r and break Full cancellation. A correct change needs a single authoritative stage reference available to both actual evaluations, including retries, accepted-state and optional tangent/adjoint paths; this is not achieved by the present `U_ref_stage_` contract. Full must remain the original operator, and stale reference or halo/projected-state mismatches must fail rather than quietly change the split.

The standard ARK324 order conditions apply directly to fixed additive functions FI(U), FE(U). If r depends on each stage/history, the partition is stage-dependent even though FI(U,r)+FE(U,r)=F(U) at each stage. The conventional fixed-split order proof cannot simply be cited; matching output weights alone does not prove third order. Derive the resulting generalized stage-dependent coupling conditions or prove equivalence to a fixed/autonomous split, and test asymptotic third-order against a smooth nonlinear manufactured/reference problem. Adaptivity, failed/retried stages and any reference refresh also need a deterministic contract. No order reduction or preservation is asserted here without that analysis.

## Existing code reuse and limits

`wrf_mass_flux()` (`:15819`) supplies current Ru/Rv, mass tendency and Omega in one memoized, differentiable WRF calculation. `wrf_horizontal_momentum` (`wrf_sdirk3_horizontal_momentum.h:15`) accepts U/V/W transported arrays separately from Ru/Rv mass-flux arrays, so reference velocities can be passed without duplicating the horizontal stencil; it returns six divergences, not producer faces. Scalar `advect_scalar_x/y` (`tile_unified_impl.cpp:27855,28149`) accept a transported field and current mass flux and can emit actual face tensors. `wrf_vert_adv3` (`:792`) and W-specific `wrf_vert_adv3_w` (`:841`) accept q and current Omega, but W has its own lid rule and no face output. All must be called with consistent high-order selection and unit/map reweighting; do not substitute a lower-order stencil, freeze Omega, or infer momentum-face conservation from divergence-only output.

For fixed current flux/velocity, existing order-2/3/5 interpolants appear linear in transported q: their sign choice depends on current velocity, not on q. If this is verified for every boundary/stagger branch, Slow may reuse the same operator on q−r rather than evaluate two separate flux operators. Exact Full reconstruction in floating point is then tolerance-based (order of operations differs), and diagnostics must capture the *actual net faces* once, not derive unrelated faces afterward. Upwind sign masks have their own nondifferentiability and established AD convention; fixed-q linearity does not establish smoothness in current velocity or validate that JVP.

Even with reference interpolation cached, current mass flux/Omega must be recomputed and differentiated at every nonlinear/JVP evaluation; horizontal and vertical operations, memory traffic and FGMRES/Newton iteration counts may outweigh any saved q-derivative work. Existing helpers are not evidence of runtime savings. Measure on identical state, precision, compiler/rank and workload; source-level costs, preconditioner mismatch and the observed whole-transport mode4 cost cannot determine a faster split by themselves.

Necessary evidence before consideration: algebraic same-state Full=Fast+Slow with common reference and producer faces per partition; deliberately mismatched-reference negative control; constant scalar and permissible staggered momentum with nonuniform hybrid levels and exact seam/wall/lid identities; mode3 Full parity; current-state FWAD versus fixed-reference central FD and genuine reference-chain tangent; accepted-stage rather than later-recomputed face/heat/mass budgets; temporal order; failure/retry and halo contracts; and same-setup WRF/RK3 field/runtime evidence. None was run here.
