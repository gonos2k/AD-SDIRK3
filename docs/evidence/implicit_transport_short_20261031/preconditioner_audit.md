# Mode-4 raw principal preconditioner: bounded source audit

Source `/private/tmp/noise-physical-split-20261031` draft mode 4. No build, source modification, or model run for this review. The type-2 raw principal selector (`wrf_sdirk3_unified_preconditioner.cpp:5241–5367`) currently requires mode 3; unsupported profiles intentionally use Legacy (:450–473), which can confound mode-3/4 work comparisons.

The raw coefficient builder (:5545–5631) uses bound current mass, PH, perturbation theta + 300, pressure/EOS, hybrid c1/c2 and eta metrics to build vertical pressure/geopotential K and theta-to-W B; G=gI and the tridiagonal Schur is I−(dt·gamma)^2 gK. It has no mode-3-only theta-mass reaction coefficient and supports stages 1–4 (:5385). Mode 4 reuses the same ARK324 table and diagonal gamma; the Newton bind and update paths key off `raw_principal_enabled`, not a separate mode3 comparison. The preconditioner is explicitly an approximate vertical principal model, not a factorization of the entire fast Jacobian.

At a horizontally uniform, quiescent base, take a horizontally replicated W/PH/theta/mu perturbation with zero horizontal velocity-divergence perturbation. The WRF diagnosed δOmega and δMdot are zero, the added current-state horizontal and vertical transport variations vanish, and the mode3 and mode4 vertical principal action is the same in this ideal subspace. At a nonuniform evolving state, transport introduces horizontal flux Jacobians and Ω(δu,δv) coupling to background gradients; these may be large at high wavenumber and are omitted by the model. It is therefore incorrect to assert full-A equality, spectral equivalence, or guaranteed conditioning.

Allowing mode4 alongside mode3 **only in this selector**, while retaining every other existing profile guard and validating actual mode4 stage binding, is a defensible matched approximate P and removes an avoidable owner difference. Do not widen HEVI, adjoint, FP64 or other capability gates. Require the existing same-executable actual A4=I−h·J4 FWAD/FGMRES test to assert raw selection, finite P application, and independently recomputed true residual under unchanged budgets on nonzero/nonuniform state; also assert mode3 selector unchanged, guard rejection remains correct, and test relevant `h=dt*gamma` stage. A successful solve is evidence for that fixture only. Subsequent WRF mode3/4 comparisons must still record preconditioner selection and all relevant configuration, logs, true residuals and cost.
