# Y/V 파동의 전방–수반–최적화–미사용 예측 완료

작성 시각: 2026-10-11 10:01:53 JST

PR #287에서 열려 있던 실제 장시간 역문제와 분석 후 예측을 실행했다. 기존 X-only 기준은 종료 상태를 유지하며 반복하지 않았다. 같은 건조·고정계수·단일 CPU tile에서 Y 의존성과 비영 V를 갖는 한 발산파의 두 절대 계수만 추정한다. Coriolis·습윤·지형·MPI 동화 및 임의의 U/V 초기장 복원은 이번 범위가 아니다.

## 두 제어방향의 계산상 종료

| 수용 갱신 수 | 목적함수 | fresh projected gradient norm |

| 0 | 544.6283539439668 | 3893.2752541911163 |
| 1 | 7.942149580967568e-6 | 0.03603175019850823 |
| 2 | 7.913879513273548e-6 | 4.751481608572788e-8 |

두 alpha=1 갱신은 실제 비용 감소와 Armijo 조건을 만족했고, 각 수용 전방은 fresh VJP 호출의 관측 예측·checkpoint·보간구간과 정확히 일치했다. 두 BFGS secant의 곡률도 양수였다. 최대 세 갱신을 소진하기 전에 1e-5 계산 gradient 기준을 충족했다. 최종 절대 계수는 `(0.7800004730122119, -0.36000367440330777)`로 truth `(0.78,-0.36)`와의 거리는 `3.7047240411e-6`이다. Source inverse Gram은 탐색 metric이며 prior가 아니다.

역문제의 실제 native 호출은 descriptor·짧은 replay·두 RHS 방향·세 gradient·두 수용 전방으로 총 아홉 번이다. 세 960스텝 수반의 재생 기록은 내부 재현성을 확인하는 근거이며, 독립 전체 Eg 상한은 아니다. 초기 U/V/W/PH/온위/MU의 source 기준 오차도 모두 감소했다.

## 미사용 시각의 실제 예측

두 분석장의 실제 300초 checkpoint에서 각각 600초, 이어 실제 600초 checkpoint에서 900초까지 전파했다. 네 호출 모두 960×0.3125초, 동일 고정 관측 위치·R·solver 설정을 사용했다. 각 호출의 local objective는 미래 최적화 비용으로 사용하지 않았다. Source truth는 처음 고정한 41성분 선형 방정식과 truth 계수를 원래 평형장에서 전파한 값이며 미래 native 결과에 다시 맞추지 않았다.

| 절대시각 | 시작 초기장 W105 RMSE (m/s) | 최종 분석 W105 RMSE (m/s) | 시작 초기장 V 상태 RMS 오차 (m/s) | 최종 분석 V 상태 RMS 오차 (m/s) |
|---:|---:|---:|---:|---:|
| 600초 | 1.5891547299e-3 | 6.9569839401e-8 | 1.3275654915e-3 | 8.5006516814e-8 |
| 900초 | 2.3605059331e-3 | 3.9757788756e-8 | 1.9719469289e-3 | 9.4702708121e-8 |

관측창 종료 이후 선행시간은 각각 5분·10분이다. 900초의 전체 상태 RMS 오차는 다음과 같다. 단위가 다른 변수들을 하나의 norm으로 합치지 않았다.

| 변수 | 단위 | 시작 초기장 | 최종 분석 |
|---|---|---:|---:|
| U | m/s | 3.0677102444e-3 | 4.0583628469e-8 |
| V | m/s | 1.9719469289e-3 | 9.4702708121e-8 |
| W | m/s | 2.5839839943e-3 | 5.8873474743e-8 |
| PH | m²/s² | 3.9788097999e-3 | 1.2606699984e-5 |
| 온위 | K | 4.3003363287e-5 | 3.0083847516e-8 |
| MU | Pa | 8.2872531458e-3 | 1.4966439191e-5 |

U의 주기 중복면과 W/PH의 고정 하단은 제외했다. V는 양끝 0인 물리 Y면을 포함한 1,664개 값이다. 전체 상태는 같은 sigma/stagger 위치 비교이며, W105는 PH에 따라 높이가 바뀌는 고정 물리 높이 관측이다. 서로 다른 평가 위치의 오차를 동일한 값으로 해석하지 않는다.

이번 예측은 `state-only cold restart`다. Solver predictor snapshot을 복원하지 않았으므로 중단 없는 warm 궤적의 비트 재현을 주장하지 않는다. Source truth는 독립 선형 기준이며 일반 비선형 대기 truth나 실관측 예보성능 검증이 아니다. 계산상 종료와 작은 상태 오차는 엄밀한 전체 gradient 오차 상한 또는 전체 상태 정지점 인증이 아니다.

- [x] 동일 두 제어·관측·R·시간간격의 실제 960스텝 전방–수반 실행.

- [x] 실제 수용 분석장의 미사용 600·900초 예측과 비영 V 포함 전체 상태 비교.
- [x] 최소 연구 CI: 다섯 CTest·16스텝 full/replay 일치·metadata 소비.
- [x] 예측 원시 배열의 최종 Green/Red 독립 검산: 해시·CRC·고정 문맥·네 상태 전달·source 재전파·60개 상태 블록 비교 및 W105 오차 재계산 통과.

새 helper는 artifact/input/source/executable 해시, 고정 절대 제어좌표, 평형 기준장, whitened H_BG 특이값, terminal gradient 링크를 확인한다. 저장된 H_BG는 물리 단위이며 보고 특이값은 H_BG/sigma이므로 같은 정규화를 적용했다. 모의 실행은 이 연결만 검사하며 실제 native 검증으로 합산하지 않았다. Graphify의 34개 source binding은 현재 코드와 일치한다. 중복·dangling edge 및 동적 subprocess 추출 한계는 기록했으며 그래프를 수치적 정확성의 증명으로 사용하지 않았다.

생산 C++·Fortran 및 native 시험 CPP는 변경하지 않았다. 새 WRF `em_b_wave` 실행이나 동일 설정 RK3 필드·runtime 비교를 수행하지 않았고, 이전 적합 회귀 근거를 새 실행과 구분한다. 자동 CI를 배포·설치·플랫폼·전체 시험으로 확대하지 않았다.

다음 작업은 이 동일 문제의 비용을 더 낮추는 반복이 아니라, 별도 목표가 정해지면 물리 범위 또는 제어공간 한 가지를 확대하는 것이다. 현재 선택한 Y/V 발산파 기준 사례는 위 경험적 범위에서 종결한다.
