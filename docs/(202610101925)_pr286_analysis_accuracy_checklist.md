# PR #285 후속 정확도 체크리스트

작성 시각: 2026-10-10 19:25:11 JST

기준: main cd1986edc181143f3471dcaf5746acf035bddf04. PR #285에서 완료한 계산상 최적화와 미사용 W 예측은 다시 열지 않는다. 원래 사용자 작업트리는 변경하지 않고 별도 worktree에서 작업한다.

- [ ] 현재 terminal 분석장에서 predictor를 유지한 전방과 상태 전용 cold restart를 한 번 대조한다. 같은 물리 상태·설정·실행파일을 사용하고, 차이를 기존 예측 오차 규모와 비교한다. 기존 CarriedState snapshot만 재사용하며 범용 restart API를 만들지 않는다.
- [ ] 같은 terminal 점과 시간간격에서 네 제어방향의 독립 관측 응답 차분을 확인한다. 비용 스칼라 뺄셈 대신 고정 관측 잔차와 응답 차분으로 gradient를 계산한다. 절단·반올림·풀이 불확실성을 구분하고 Eg 인증의 근거가 부족하면 명시한다.
- [ ] 이미 저장된 native 초기장·분석·예측을 같은 source truth의 U/V/W/PH/온위/MU와 변수별 단위로 비교한다. 국소 delta를 절대 truth 계수로 오인하지 않는다. eta 위치와 Eulerian 고도 변수를 구분한다.
- [ ] Green/Red 팀이 소스·실행 계보·독립 재계산·완료 범위를 검토한다.

자동 CI는 기존 5개 CTest, 16스텝 재생, metadata consumer 및 문법 검사를 유지한다. 필요한 장시간 실험만 수동 실행한다. 배포·설치·전체 시험·플랫폼 확대는 이번 범위에 포함하지 않는다.

생산 수치 방정식 변경은 현재 계획에 없다. 새 WRF 실행 및 동일 설정 RK3 필드/시간 비교는 아직 수행하지 않았다. 변경이 시험용 코드에 한정되면 적합한 PR #283 WRF/RK3 근거를 재사용하고 이를 새 실행과 구분한다. Graphify는 관련 의존성 탐색에 사용하며 수학적 증명으로 취급하지 않는다.
